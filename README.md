Ikuti langkah berikut untuk memulai:
1. Install dependency: 
    $ pip install -e .
2. Jalankan server: 
    $ hatch run manage.py runserver

REST API v1 menggunakan Django REST Framework. Dokumentasi endpoint dan contoh autentikasi ada di
[API.md](API.md); OpenAPI tersedia pada `/api/v1/schema/` dan Swagger UI pada `/api/docs/`.
